# Help and explanations

Open this help with {help} anywhere nothing is typed, and with {help.f9} also in a text field. On macOS a function key often needs fn. Close it with the same key or with {back}. Press {search} in it to search the text of all pages.

- The `Help` area opens the help, the explanation of the sample data ({info}) and the command line ({command}).
