# Tabs and switches

Every tab shows one group of building blocks with **invented data**. Open a tab with its digit ({area}) and quit with {quit}.

- The switches act at once:
  - {set.theme} changes the theme
  - {set.language} changes the language
- The key list at the end of the page names the keys of the screen you came from.

The sample data is an invented [garden journal](https://example.org/journal).
